## 🎯 Задача (The Challenge)

Платформа inVision U уже работает: абитуриенты **записывают видеоответы**, а комиссия **просматривает каждую запись вручную**. Этот шаг плохо масштабируется — на каждого кандидата уходят часы, внимание рассеивается на длинных очередях, а уровень английского выясняется только после того, как человек уже потратил время на заявку.

**Что мы добавили во время хакатона:**

1. **AI-агент на месте видеозаписи** — вместо односторонней записи абитуриент в реальном времени разговаривает с эмпатичным AI-интервьюером. Он ведёт структурированный поток из 6 вопросов, уточняет общие ответы («воду») через фреймворк ATOLA, транскрибирует всё и передаёт комиссии оценку с цитатами (9 компетенций по шкале BARS).
2. **Шаг тестирования английского (IELTS/CEFR) с AI-прокторингом** — быстрый верифицируемый тест, который показывает, куда переводить кандидата дальше: **подготовительный год (foundation) или прямой приём**.
3. **Инструменты комиссии вокруг этого** — очередь триажа, глубокий анализ и сравнение кандидатов, чтобы рецензенты тратили минуты, а не часы.

## 🚀 Что добавили (What We Added)

Реализовано поверх существующей платформы inVision U (регистрация, анкета и исходный флоу «запись → ручной просмотр» уже были):

- **Голосовой AI-интервьюер (замена шага ручного просмотра):** Двусторонний аудиостриминг с минимальной задержкой по WebSocket на базе Google Gemini Live API (`gemini-3.1-flash-live-preview`), с автоконтролем тишины и корректным завершением сессий.
- **Движок ATOLA-пробинга и детекция «воды»:** Динамические уточняющие вопросы по элементам Action, Thinking, Outcome, Learnings, Application — фильтрация заученных ответов в реальном времени.
- **Новый шаг: тестирование английского (English Gate):** Тестирование грамматики, словарного запаса, письменной и устной речи с AI-прокторингом в браузере (трекинг взгляда, лица, предотвращение переключения вкладок) — определяет маршрут кандидата: подготовительный год или прямой приём.
- **ML-пайплайн анализа:** 8 эвристических модулей без тяжелых внешних зависимостей (оценка компетенций IAF, анализ подлинности, соответствие базовому уровню, оценка уровня языка).
- **Оценка 9 компетенций по шкале BARS:** Поведенческая шкала оценки мотивации, лидерства, жизнестойкости, гибкости мышления и командной работы с верифицируемыми цитатами из речи кандидата.
- **Рабочее место приёмной комиссии:** Административный дашборд с карточками кандидатов, экраном детального сравнения (`/admin/compare`), историей диалогов (Candidate Chat), просмотром видеозаписи и очередями триажа.
- **Готовая инфраструктура:** Контейнеризация через Docker Compose, обратный прокси Traefik, автоматические Let's Encrypt SSL-сертификаты через `nip.io` и поддержка локального/облачного S3-хранилища.

## 🏁 Быстрый старт (локальный запуск)

### Требования
- Docker и Docker Compose
- Node.js 20+ и `pnpm` (для фронтенда)
- Python 3.10+ (для бэкенда)
- Ключ Google Gemini API

### Запуск через Docker Compose

1. **Настройка переменных окружения бэкенда:**
   ```bash
   cp backend/.env.example backend/.env
   ```
   В файле `backend/.env` укажите:
   - `GEMINI_API_KEY`: Ваш ключ Google Gemini API
   - `JWT_SECRET`: Секретная строка (например, сгенерированная через `openssl rand -hex 32`)

2. **Запуск бэкенда и базы данных:**
   ```bash
   docker compose up -d --build
   ```

3. **Запуск фронтенда:**
   ```bash
   cd frontend
   pnpm install
   pnpm dev
   ```

4. **Доступ к сервисам:**
   - **Фронтенд:** [http://localhost:3000](http://localhost:3000)
   - **Бэкенд API и Swagger Docs:** [http://localhost:8001/docs](http://localhost:8001/docs)

### Жизненный цикл интервью

1. **Регистрация / Вход** → выдача JWT-токена.
2. **English Gate (опционально/обязательно)** → тестирование CEFR/IELTS с AI-прокторингом.
3. **Заполнение анкеты** → сохранение данных кандидата в БД.
4. **Старт интервью** → создание сессии, инициализация камеры и микрофона.
5. **WebSocket стриминг** → двусторонняя передача PCM-аудио через Gemini Live API.
6. **ATOLA-пробинг** → агент выявляет поверхностные ответы и задаёт направленные уточнения.
7. **Завершение сессии** → вызов `end_session()` → сохранение структурированных заметок и таймкодов.
8. **Загрузка записи** → сохранение WebM-видео в S3-хранилище.
9. **Проверка комиссией** → расчёт оценки по 9 компетенциям BARS и назначение уровня триажа.

## 🧠 ML-пайплайн анализа

Все 8 эвристических модулей работают без тяжелых внешних библиотек машинного обучения:

1. **Качество данных (Data Quality):** Проверка полноты (все 6 вопросов закрыты) и содержательности речи (объём слов, количество реплик).
2. **Базовая оценка (Baseline Evaluation):** Независимый алгоритмический скоринг по длине ответов и ключевым индикаторам достижений.
3. **Согласованность AI и базовой оценки:** Сравнение вердикта AI с базовым скорингом (`exact`, `adjacent`, `disagreement`). Несовпадения направляются в ручной разбор (Tier 4).
4. **Анализ подлинности (Authenticity Analysis):** Выявление заученных, сгенерированных нейросетями или прочитанных по бумажке ответов (доля личных фактов, естественность пауз, N-gram пересечения с другими сессиями).
5. **Оценка языка (Language Proficiency):** Определение уровня CEFR (A1–C2) и эквивалента IELTS по грамматике, словарному запасу, беглости и связности речи.
6. **Оценка компетенций IAF:** 7 измерений с весами в зависимости от выбранной программы (мотивация, жизнестойкость, видение, командность, самосознание, подлинность, вклад).
7. **Модуль объяснимости (Explainability):** Понятная интерпретация для комиссии: текстовое резюме, ключевые аргументы «за» и «против», веса вопросов и прямые цитаты.
8. **Поиск аномалий (Error & Edge Cases):** Обнаружение смысловых противоречий между оценкой и содержанием транскрипта, выбросов и пропущенных ответов.

### 4-уровневая очередь триажа абитуриентов

| Уровень | Категория | Время проверки | Критерии |
| :--- | :--- | :--- | :--- |
| **Tier 1** | **Fast Track** | ~5 мин | Высокие баллы, полные ответы, полное совпадение AI и базовой оценки, нет аномалий. |
| **Tier 2** | **Standard Review** | ~12 мин | Стабильный профиль со сбалансированными оценками. |
| **Tier 3** | **Hold Queue** | ~5 мин | Вердикт `not_recommended` или низкие профильные компетенции. |
| **Tier 4** | **Manual Required** | ~45 мин | Риск заученного/AI-текста, противоречия в ответах или расхождение AI с базовой моделью. |
